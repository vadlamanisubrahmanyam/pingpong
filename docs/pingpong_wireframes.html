v1.0 · Android 9+ · black background, white elements · amber numbers mark annotated elements (not part of the app UI).

Screen flow

Screens

1. Main Menu

Entry point. Black screen, white elements.

  1. 1
    Title + ballStatic title and a single white ball.
  2. 2
    START GAMEOpens Select Level.
  3. 3
    SETUPOpens the admin Setup screen.
  4. 4
    EXITCloses the app (also: BACK on this screen).
  5. 5
    Credit'Developed by Subrahmanyam' shown on the menu.

2. Select Level

Pick a difficulty; the match starts immediately.

  1. 1
    EASY / NORMAL / HARDTap to start a match using that level's Setup values (ball speed, paddle size).
  2. 2
    First to N winsReads the score-to-win value from Setup.
  3. 3
    Control infoShows the current control (TOUCH or TILT) and reminds that it is changed in Setup.
  4. 4
    BACKReturns to Main Menu.

3. Setup (Admin)

Four configuration groups, saved automatically on the device. A small 'Screen stay-awake' status line at the bottom shows whether the screen-awake protection is active (NATIVE, WEB, NATIVE+WEB or OFF).

  1. 1
    1. Score to win- / + stepper, range 3-21, default 7.
  2. 2
    2. Ball speedOne slider per level, 150-500 units/s. Defaults 240 / 300 / 380.
  3. 3
    3. Paddle sizeOne slider per level, 40-140 px (the player's paddle line). Defaults 96 / 72 / 56.
  4. 4
    4. ControlCONTROL: TOUCH / TILT toggle. In tilt mode a DIR: NORMAL / REVERSED button appears to flip the tilt direction.
  5. 5
    Tilt test barTilt mode only. The dot follows the device tilt so the direction can be checked without playing.
  6. 6
    RESET DEFAULTSRestores all values above and sets control back to TOUCH.
  7. 7
    BACKSaves and returns to Main Menu.

4. Gameplay

Portrait court, paddles top and bottom.

  1. 1
    AI paddleFixed 72 px; speed and accuracy depend on level.
  2. 2
    BallWhite ball, speeds up 5% per paddle hit up to a level cap.
  3. 3
    Score + targetAI score above the centre line, player below, with FIRST TO N (N from Setup) shown between them.
  4. 4
    Player paddleWidth from Setup. Drag to move, or tilt the device.
  5. 5
    Centre lineDashed line, visual only.

5. Game Over

Shown when either side reaches the configured score.

  1. 1
    ResultYOU WIN or YOU LOSE.
  2. 2
    Tap to continueReturns to Main Menu.
